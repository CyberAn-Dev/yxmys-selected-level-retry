
# 英雄没有闪：纯画面爬塔自动化起步项目

这是一个 Windows + Python 的视觉自动化示例。

它不会读取游戏内存、网络请求或小程序内部接口。状态判断来自屏幕像素：

1. 在难度选择界面，找出最靠下的非灰色难度行。
2. 点击该难度，再点击“挑战深渊”。
3. 检测“开始挑战”弹窗并点击。
4. 战斗中不操作。
5. 检测“点击关闭”，关闭胜利或失败结算。
6. 回到第 1 步循环。

窗口位置通过 Windows 窗口标题定位，这是为了防止窗口移动后坐标失效；游戏状态识别仍是视觉方案。

## 安装

在 Windows PowerShell 中进入项目目录：

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

## 运行

1. 打开微信小程序独立窗口。
2. 确保窗口标题包含“英雄没有闪”。
3. 确保窗口没有被其他窗口遮挡。
4. 运行：

```powershell
python bot.py
```

热键：

- `F8`：开始或暂停
- `F9`：退出
- 鼠标移到主屏幕角落：PyAutoGUI 急停并暂停

## 识别逻辑

### 最高可用难度

不需要 OCR，也不需要读出 44、45、46。

程序检查五个难度行的 HSV 饱和度：

- 红色/粉色行：饱和度高，判定为可选
- 灰色行：饱和度低，判定为未解锁

然后选择最靠下的可选行。

### 三个界面状态

`templates` 文件夹中有三个小模板：

- `challenge.png`：挑战深渊
- `start.png`：开始挑战
- `close.png`：点击关闭

识别优先级：

1. 点击关闭
2. 开始挑战
3. 挑战深渊

这个顺序很重要，因为弹窗出现时，底层的“挑战深渊”按钮仍可能被模板匹配到。

## 需要调整的参数

都在 `bot.py` 顶部：

- `WINDOW_TITLE`：窗口标题
- `MATCH_THRESHOLD`：模板匹配阈值
- `UNLOCKED_SATURATION_THRESHOLD`：可选行颜色阈值
- `ROW_CENTERS`：五个难度行的位置
- `ACTION_COOLDOWN`：两次操作之间的冷却时间

如果日志显示：

```text
没有识别到可选难度：[...]
```

观察其中的五个饱和度数值。通常可选行会明显高于灰色行，再把阈值设在两组数值中间。

## UI 改版或模板失效

项目中的模板由你提供的三张 550×1020 截图裁剪而来。

要用新的三张截图重新生成：

```powershell
python make_templates.py 选择界面.png 确认弹窗.png 结算界面.png
```

截图应只包含小程序窗口，并保持与原图相同的整体布局。

## 限制

- 小程序窗口必须保持可见，不能被遮挡。
- 如果游戏改版、动画差异很大或难度列表发生滚动，需要更新模板或行坐标。
- 若“点击关闭”闪烁太快，可以降低 `LOOP_INTERVAL`，例如改为 `0.15`。
- 自动化可能违反游戏或平台规则，也可能造成账号处罚。建议只在你有权操作的设备和测试账号上使用。
